###  The Problem: Coding Agent Amnesia

Autonomous coding agents (Google Antigravity, Command Code, Meta Muse, OpenAI Codex) operate in isolated, ephemeral sessions:
1. **Vanishing Rationale:** Design decisions, invariants, and architectural constraints are lost between sessions.
2. **Silent Workspace Drift:** Files change unexpectedly without verification against prior contracts.
3. **No Cross-Harness Continuity:** A task started in Antigravity cannot resume in Command Code or be handed off to a teammate without manual context reconstruction.

---

### ⚡ The Solution: VectorForce

VectorForce introduces a cryptographic, local-first context protocol that links:
- **Verifiable Evidence:** Git commits, file SHA-256 hashes, and workspace drift.
- **Model Claims:** Explicit task goals, non-negotiable constraints, and Architectural Decision Records (ADRs).
- **AI Memory & Reasoning:** Meta Llama / Muse reasoning layer that synthesizes where you left off, what changed, architectural risks, and ranked next actions.

---

### 🖥️ VectorForce Studio

A local-first engineering control center running natively on your machine:

- **Interactive Topology Graph:** SVG module dependency mapping, blast radius inspection, and drift alerts.
- **AI Workspace Console:** Real-time prompt reasoning with strict *Claims vs Evidence* visual fencing.
- **Repository Memory & Timeline:** Symbol search, allowlisted document index, and weekly continuity recaps.
- **Team Handoffs:** Privacy-safe context export/import without leaking credentials or unallowlisted files.

---

### 🔌 Cross-Harness Support

VectorForce standardizes context continuity across:
- **Google Antigravity** (`.gemini/antigravity`, native MCP protocol)
- **Command Code** (`.commandcode/taste`)
- **Meta Muse** (`.agents/mcp_config.json`)
- **OpenAI Codex** (`.codex/config.toml`)
